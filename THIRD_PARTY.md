# Third-party components

Applications and model weights are installed separately, not relicensed by this package.

- Handy: https://github.com/cjpais/Handy
- Ollama: https://github.com/ollama/ollama
- Piper: https://github.com/OHF-Voice/piper1-gpl
- Piper voices and individual model cards: https://huggingface.co/rhasspy/piper-voices
- Vosk and model licenses: https://alphacephei.com/vosk/models
- sounddevice: https://python-sounddevice.readthedocs.io/
- Pillow: https://python-pillow.github.io/
- Qwen models: consult the model cards for the Ollama tags installed by Setup-Models.ps1.

The ready tone is generated mathematically. No user-provided sound is distributed.
Additional runtime components: NumPy and webrtcvad-wheels; see their upstream licenses.
No open-source license for the original LEVI glue code is assigned here; the owner should choose one before distributing permissions to reuse it.
